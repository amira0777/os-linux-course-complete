# Скрипты курса

Скрипты здесь — вспомогательные инструменты ведения самого учебного
репозитория, а не команды для изменения системы.

- `commit-course.sh` — вручную запускаемый сценарий последовательного
  коммита подготовленных материалов в пустой репозиторий на ветке `main`.
  Он сбрасывает переменные Git для подмены дат и использует обычное системное
  время. Скрипт нужно сначала прочитать; автоматически он не запускается.

Все учебные эксперименты с системными настройками следует выполнять
вручную и только в отдельной виртуальной машине.
