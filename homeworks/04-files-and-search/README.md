# Задание 04 · файлы, маски, поиск и справка

## Цель

Научиться управлять файлами в ограниченном учебном каталоге, понимать
раскрытие шаблонов оболочкой и пользоваться встроенной документацией.

## Подготовка

Создайте `~/os-course/files-practice/inbox` и заполните его самостоятельно
минимум двенадцатью тестовыми файлами: текстовыми отчётами (включая имя с
пробелом), изображениями с двумя расширениями, журналами, CSV и резервными
копиями. Добавьте скрытый файл. Не скачивайте для упражнения реальные данные.

## Задания

1. Создайте внутри `files-practice` каталоги `sorted/docs`, `sorted/images`,
   `sorted/logs` и `sorted/data`.
2. Переименуйте файл с пробелом, используя корректное экранирование или
   кавычки.
3. Переместите текстовые отчёты, изображения и журналы в соответствующие
   каталоги, предварительно проверив совпадения каждой маски.
4. Скопируйте CSV-файлы, оставив оригиналы на месте.
5. Покажите разницу между `*`, `?` и символьным классом на своих тестовых
   именах.
6. Найдите файлы по имени, расширению и времени изменения при помощи `find`.
   Запишите результат в файл вне каталога, который сканируете.
7. Найдите скрытый файл и объясните, почему обычный `ls` может его не показать.
8. В справке `man ls` найдите опцию сортировки по размеру и примените её к
   `sorted/images`.
9. Проверьте команду `locate`, объясните источник её индекса и укажите, почему
   результат может быть устаревшим.
10. Перед удалением резервных копий покажите список совпадений и только затем
    удалите их внутри `files-practice`.

## Что сдать

Отчёт с командами, кратким журналом попыток, содержимым итогового дерева и
пояснением, как проверка пути и списка файлов предотвращает ошибочное удаление.
Не используйте `rm -rf` с широкими шаблонами.
