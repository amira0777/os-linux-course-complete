# Задание 06 · права доступа и `umask`

## Цель

Разобраться в правах чтения, записи и выполнения, владении объектами и
специальных битах.

## Задания

1. В учебном каталоге создайте файл и каталог. Для владельца, группы и прочих
   объясните, что меняется при добавлении или снятии каждого базового права.
2. Запишите два представления прав — буквенное и числовое — для шести
   придуманных режимов. Для каждого объясните ожидаемое поведение.
3. Сравните `chmod` и `chown` на собственных временных объектах.
4. Рассчитайте ожидаемые права новых файла и каталога для двух значений
   `umask`; проверьте расчёт созданием тестовых объектов.
5. На схеме общего каталога объясните назначение setgid и sticky bit.
6. Предложите права для конфиденциального файла и публичного каталога проекта,
   аргументируя выбор по модели угроз.
7. Укажите, когда обычные права недостаточны и стоит рассмотреть ACL.

Все эксперименты выполняйте в личном учебном каталоге. Не меняйте права
системных директорий, домашнего каталога пользователя или всей файловой
системы рекурсивно.

## Что сдать

Таблицу из шести объектов с владельцем, группой, режимом в двух форматах,
ожидаемыми пользователями и фактической проверкой; расчёты `umask`; объяснение
setgid/sticky и краткий вывод.
