# Задание 05 · пользователи, группы и доступ

## Цель

Спроектировать ролевую модель доступа к каталогу проекта и проверить её на
изолированной машине.

## Проектная часть

Для вымышленной команды `mobile-app` определите роли руководителя,
разработчика, тестировщика и гостя. Разделите исходный код и отчёты о тестах
по разным каталогам. Для каждого участника укажите основную и дополнительные
группы и ожидаемые операции чтения, записи и входа.

## Практическая часть

Только в отдельной одноразовой виртуальной машине:

1. Создайте группу проекта и учебные учётные записи без паролей, пригодных
   для реального использования.
2. Настройте два каталога проекта и назначьте соответствующие группы.
3. Проверьте доступ обычными командами от имени тестовых пользователей.
4. Заполните матрицу «участник × каталог × операция» ожидаемыми и фактическими
   результатами.
5. Проверьте, что непривилегированный участник не получает доступ к
   запрещённым операциям.
6. Зафиксируйте один отказ доступа и объясните, какие проверки Linux привели
   к нему.
7. Удалите учебные учётные записи и каталоги после проверки.

Не выдавайте группе проекта членство в `sudo` без отдельного обоснования.
Не включайте реальные пароли или их хеши в отчёт.

## Что сдать

Схему ролей, матрицу доступа, список команд без секретных данных, результаты
проверок и объяснение принципа минимальных привилегий.
