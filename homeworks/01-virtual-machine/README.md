# Задание 01 · учебная виртуальная машина

## Цель

Подготовить изолированное окружение Linux, пригодное для последующих
экспериментов, и уметь проверить его основные параметры.

## Выполнение

1. Создайте виртуальную машину и установите Ubuntu из официального образа.
   Запишите источник образа и способ проверки его контрольной суммы.
2. Сделайте снимок виртуальной машины после установки.
3. Выполните `cat /etc/os-release`, `uname -a`, `id`, `pwd` и `df -h`.
4. По каждой команде объясните, какую характеристику она показывает.
5. Проверьте, что обычный пользователь может открыть терминал и создать файл
   в домашнем каталоге.
6. Сравните конфигурацию виртуальной машины с требованиями выбранного выпуска.

## Что сдать

`README.md` с описанием гипервизора, выпуска Ubuntu, ресурсов виртуальной
машины, контрольной проверки образа, командами и фактическими результатами.
Добавьте один снимок окна с информацией о системе; скройте имя пользователя,
если не хотите его публиковать.

**Ограничение:** не загружайте образ из неизвестных зеркал и не используйте
виртуальную машину с доступом к чувствительным данным.
