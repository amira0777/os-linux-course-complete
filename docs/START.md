# Начало работы

## Учебная среда

Используйте актуальный образ Ubuntu и VirtualBox, VMware или другой
гипервизор, доступный на вашем компьютере. Скачивайте образ только с
официального сайта Ubuntu и по возможности сверяйте контрольную сумму,
опубликованную для этого выпуска.

Рекомендуемый порядок:

1. Создайте новую виртуальную машину без доступа к важным данным хоста.
2. Выделите ресурсы, достаточные для выбранного выпуска, не забирая их у
   основной системы.
3. Установите ОС и зафиксируйте состояние виртуальной машины до работ,
   требующих `sudo`.
4. Откройте терминал и соберите базовые сведения:

   ```sh
   cat /etc/os-release
   uname -a
   id
   pwd
   ```

5. Создайте снимок виртуальной машины перед практиками с пользователями,
   группами, правами и процессами.

## Правила эксперимента

- Все создаваемые учебные файлы храните в отдельном каталоге домашней папки.
- Перед командой удаления сначала проверьте текущий путь и список совпадений.
- Не запускайте скопированные команды, смысл которых не понимаете.
- Не применяйте `sudo` по умолчанию: сначала выясните, достаточно ли обычного
  пользователя.
- Запишите выпуск системы, дату проведения опыта и команды, необходимые для
  его повторения.
