# Лабораторная 01 · паспорт системы и воспроизводимость

## Цель

Получить компактный, безопасный для публикации паспорт учебной системы и
проверить, сможет ли другой студент повторить исследование.

## Протокол

1. Укажите дату, тип среды (физическая машина или VM), дистрибутив, выпуск,
   ядро, архитектуру и оболочку.
2. Для каждой характеристики выберите команду или системный источник и
   сохраните только релевантную часть вывода.
3. Независимо проверьте минимум две характеристики двумя способами. Объясните
   совпадение или различие.
4. Составьте перечень файловых систем и точек монтирования из доступного
   вывода `findmnt` или `df -hT`.
5. Удалите из публикуемого отчёта серийные номера, MAC-адреса, имена
   пользователей и внутренние адреса, если они не нужны для вывода.
6. Попросите другого человека повторить один безвредный шаг по вашему описанию
   или самостоятельно повторите его после перезапуска терминала.

## Что сдать

- `investigation.md` — таблица характеристик, источников и расхождений;
- `reproducibility.md` — точные шаги повторения, предпосылки и ожидаемый тип
  результата;
- `system-passport.md` — краткий итог без секретных и избыточных сведений.

Используйте шаблоны из `reports/`. Фактические значения вписывайте только
после выполнения команд на собственной машине.
